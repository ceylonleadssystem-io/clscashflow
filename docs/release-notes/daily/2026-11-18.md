# Ceylonry POS: Release Notes, 2026-11-18

Changes shipped in the last 24 hours: ingredient checks now happen when you pick an item (issue #163), and a Menu Admin fix (issue #161).

---

## Features

### Ingredient check when an item is selected
**What it does.** An item whose ingredients are short can no longer be added to an order. Before, the problem only showed up at payment.

**How it works.** Applies when **Recipes / stock usage** is on (ingredients are deducted when an item is sold).
- On the order screen, an item that cannot be made is greyed out and says **Not enough <ingredient>** on its tile.
- The check counts what is already in the current order, so two orders of the same item cannot use up the same ingredient twice.
- Adding the item, or raising its quantity (+), shows a message such as "<Item> cannot be added: not enough <ingredient> (needs X, Y available)."
- Only the item's own ingredients are checked. Another item being short never blocks it.
- Items with enough ingredients work as before. The stock check at payment is unchanged.

**Steps**
1. Open the order screen and look at the item tiles.
2. A greyed tile with **Not enough <ingredient>** cannot be tapped. Restock that ingredient in Inventory to bring it back.
3. If you press **+** on a line in the order and stock is short, a message tells you which ingredient and how much is available. The quantity stays the same.

## Fixes

- **Menu Admin no longer crashes when changing an item's location (issue #161).** It happened for items with no saved locations. Reloading did not help. The change now shows normally in the list of pending edits, as "All locations" or a location count.
