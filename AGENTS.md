# IMPORTANT: This is NOT a rebuild of the POS system.

The POS already has its existing features, workflows, backend logic, permissions, inventory behaviour, reporting, checkout process, payment handling, offline capability, staff controls, receipt handling, product management, customer management and other functionality.

**Keep every existing feature exactly as it is unless a UI adjustment is required to display it better.**

The task is to **tweak and modernise the design only**:

- Improve layout
- Improve spacing
- Improve typography
- Improve buttons
- Improve cards
- Improve tables
- Improve navigation
- Improve product presentation
- Improve cart presentation
- Improve responsiveness
- Improve touch usability
- Apply the new 3-colour theme system

**Do not remove, replace, simplify or recreate working features just because they are not shown in the reference mockup.**

If the current Ceylonry POS contains features that are not visible in the reference design, **retain those features and redesign them using the same new visual language.**

Treat supplied UI images strictly as **visual direction/references**, not as the full functional specification.

Before making changes, audit the existing application and preserve:

- Existing routes
- Existing components where practical
- Existing APIs
- Existing database logic
- Existing permissions
- Existing calculations
- Existing integrations
- Existing offline behaviour
- Existing POS workflows

Refactor styling and presentation rather than rewriting working business logic.

## Primary objective

`CURRENT CEYLONRY POS + ALL CURRENT FEATURES + BETTER UI/UX + 3 THEMES`

## Not the objective

`NEW POS SYSTEM BASED ONLY ON THE MOCKUP`

If any existing feature conflicts visually with the new layout, adapt the design around the feature rather than removing the feature.

## Visual direction

Continue with the supplied Ceylonry POS UI specification and reference artwork. Use its cleaner spacing, modern cards and tables, dark navigation, clear orange accent, product imagery, readable cart hierarchy, responsive layouts and touch-friendly controls while retaining every current feature and workflow.
